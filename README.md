# นโยบายความเป็นส่วนตัว — RUBSARB WHATEVER - intro

ปรับปรุงล่าสุด: 12 ตุลาคม 2026

นโยบายนี้อธิบายการทำงานของ RUBSARB WHATEVER - intro รุ่น 1.0.3 ส่วนขยายเล่นอินโทร WHATEVER ความยาว 20 วินาทีก่อนคลิปของช่อง RUBSARB เมื่อเริ่มคลิปที่ 00:00

## ข้อมูลที่ส่วนขยายอ่านและใช้

ส่วนขยายทำงานเฉพาะบน https://www.youtube.com/* โดยอ่าน URL ของหน้าที่เปิดอยู่ รวมถึงรหัสคลิปและเวลาเริ่มในลิงก์ อ่านรหัสช่องเจ้าของคลิป และอ่านสถานะเครื่องเล่น เช่น ตำแหน่งการเล่น การกรอเวลา ระดับเสียง และสถานะปิดเสียง

ข้อมูลเหล่านี้ใช้เพื่อระบุคลิปของช่อง RUBSARB ตรวจว่าคลิปเริ่มที่ 00:00 ตั้งเสียงอินโทรให้ตรงกับเครื่องเล่น และหยุดหรือเล่นคลิปต่อเมื่ออินโทรจบหรือผู้ใช้กดข้าม

## การจัดเก็บและการส่งข้อมูล

ข้อมูลถูกประมวลผลชั่วคราวในหน่วยความจำของหน้าปัจจุบัน ส่วนขยายไม่บันทึกประวัติการรับชมลงไฟล์ ฐานข้อมูล หรือพื้นที่จัดเก็บถาวร ไม่ส่งข้อมูลที่อ่านให้ผู้พัฒนา เซิร์ฟเวอร์ภายนอก หรือบุคคลอื่น

ส่วนขยายไม่มีระบบวิเคราะห์การใช้งาน ไม่มีตัวติดตาม ไม่ขายข้อมูล และไม่ใช้ข้อมูลเพื่อโฆษณาหรือสร้างโปรไฟล์ผู้ใช้ ผู้พัฒนาไม่สามารถเข้าถึงข้อมูลที่ส่วนขยายประมวลผลในเครื่องได้

## ไฟล์และสิทธิ์การเข้าถึง

ไฟล์ JavaScript และวิดีโออินโทรอยู่ในแพ็กเกจส่วนขยาย ไม่มีการโหลดโค้ดระยะไกล ส่วนขยายไม่อ่านรหัสผ่าน คุกกี้ ข้อมูลบัญชี Google หรือข้อมูลจากเว็บไซต์อื่น

## การควบคุมของผู้ใช้

ผู้ใช้กดข้ามอินโทรได้ และปิดหรือลบส่วนขยายได้ที่ chrome://extensions เมื่อหน้าถูกปิด ข้อมูลชั่วคราวของหน้าจะถูกปล่อย ไม่มีประวัติที่ส่วนขยายจัดเก็บถาวรให้ต้องลบเพิ่มเติม

## การใช้ข้อมูลอย่างจำกัด

การใช้ข้อมูลจำกัดเฉพาะการแสดงอินโทรตามวัตถุประสงค์ที่ระบุข้างต้น สอดคล้องกับ Chrome Web Store User Data Policy รวมถึงข้อกำหนด Limited Use
